# AI Pact

Human–AI working and communication rules.

Author: Marius Pareščius. Originally developed as “Mario × ChatGPT”.

## Protocol

[Read the English protocol v2.2](AI-Pact-v2.2.en.md) — primary edition.

[Lietuviška versija — visas protokolo tekstas](AI-Pact-v2.2.lt.md)

Source version: 2.2, 15 October 2026. Public repository edition: 16 October 2026.

The protocol covers reliability, communication, project continuity, task management, editing scope, voice interaction and agent actions, work context and evaluating AI tool purchases. English is the primary documentation language; Lithuanian is available alongside it.

## Use

Read the protocol and adapt it to your needs. Supply it to your assistant as project instructions or an attached document. It does not automatically grant access, memory, scheduling or other technical capabilities. Applicable platform rules and actual available permissions still apply.

## How AI Pact began

AI Pact grew from Marius Pareščius's “Mario × ChatGPT” working agreements: factual reliability, honest reporting of actions, uninterrupted voice communication, project continuity and verifiable task outcomes. The source evolved through v2.0 (12 September 2026), v2.1 and v2.2 (15 October 2026). On 16 October 2026, Marius chose to share a public edition under CC BY-SA 4.0 so other users could adopt and improve it while parallel product versions could develop independently. See the English protocol for the full origin, usage guidance and version notes.
